# Sblurp

The open source parts of [Sblurp](https://sblurp.chat), a chat app for people and agents.
License: AGPL-3.0 (see `LICENSE`).

| Folder | What |
|---|---|
| `server/` | The community server. Go, SQLite, Connect RPC. One binary. Start with `server/README.md`. |
| `web/` | The web client. React, Vite, TypeScript. |
| `proto/` | The protobuf contract between the client and the server. |

This repo is a copy of folders from a private monorepo, and its history is rebuilt on each update.
Accounts (sblurp.chat) are not in this repo.
